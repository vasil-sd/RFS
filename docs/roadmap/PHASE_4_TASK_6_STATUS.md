## Plan correction (D-P4-10)
The D-P4-10 text for `neg(p U q)` targets T = gfp(¬q ∧ ¬p ∧ ∃succ∈T) with backward reachability staying in ¬q. That equation is correct for STRONG until but diverges from the WEAK-until semantics pinned by D-P4-8: it disagrees with brute-force path enumeration on **185/1200** random tiny graphs. Minimal counterexample (H2): nodes 0->1, 1<->2 with P=[T,F,T], Q all false - the path 0,1,2,1,2,... has its first not-P at position 1 with no Q before, so weak until is FALSIFIED; the literal equation's bad set is empty (node 1's successor 2 has P) and says satisfied. **Implemented (corrected) equation:** `neg(p U_W q)` = backward reachability, staying in {pos: ¬q(pos)}, to the target {pos: ¬p(pos)} - no fixpoint needed. Recorded in DESIGN section 11.
