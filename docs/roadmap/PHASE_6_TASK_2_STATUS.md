## Changed functionality

- Every generated artifact (Rust + C; production/test/mc commands; fuzz skeletons): line 1 is now `// Generated by RFS v1.0.0 | spec sha256:<hash16> | module <name>` - toolchain version + SHA-256 of the canonical IR JSON of the WHOLE input file (first 16 hex chars); one hash per artifact, multi-module files share the file's hash.
- IR JSON documents: `ir_version` now 1; readers accept {0, 1} (previous minor versions stay loadable), reject v2+ with a pinned error.
- Syntax version header: when present it must be `X.Y` or `X.Y.Z` - enforced as a semantic validation error (absent headers accepted as legacy).
- Crate version 0.1.0 -> 1.0.0; `--print-script` script headers show `rfs 1.0.0`.

- None (v0 IR documents still load; header-less specs still accepted).
